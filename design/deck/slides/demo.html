Jury criteria 4 and 5. A full run takes about ten minutes and a case takes weeks, so the demo is a sped-up recording of real agent logs, with every time jump labeled. The insurer is a scripted simulator that sends real email into a real Gmail inbox, and every simulated message is marked SIMULATED in its header and its first line. The public replay at neolorenzo.github.io/claimback plays the recorded strong-case run from its agent log. The full narration, with what’s on screen and every command, is in design/demo-script.md.

Planning

The Planner picks the strategy and the appeal type, sends each analyst its own questions, and rates merit. Revising stops early when the reviewer scores 3/10 or lower.

Handoffs

Each agent writes a schema-checked artifact to a shared run state. The next agent reads only what it needs. Invalid output goes back to the agent with the error.

Error recovery

Retries with backoff, tested with injected faults (API timeout, search outage, malformed handoff). Every stage is checkpointed, so a crashed run resumes where it stopped.

Jury criterion 2: planning, handoffs and error recovery. The orchestrator runs a fixed, auditable route, which is deliberate for safety. The Planner decides strategy and appeal type, asks the Policy Analyst and the Evidence Researcher separate questions, and both run in parallel. The Writer drafts, then the Adversarial Reviewer plays the insurer while the Fact Checker traces every claim to a source, also in parallel. Revisions are capped at three rounds, and a reviewer score of 3/10 or lower stops revising, because polishing won’t fix a weak case. Recovery is tested, not claimed: chaos mode fails the first attempt of three stages, and in the recorded run we also killed the process mid-draft and resumed from the checkpoint.
